# WIN系统应用备份重装助手（pc-rebuild-automation）

重装或升级 Windows 系统前后，记录使用者的软件清单、个性化设置与使用习惯，重装后按记录自动重建，使新系统的使用体验与原系统一致或更优；含捆绑软件卸载、系统缓存移盘、软件安装至 D: 建议等配套优化。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- **重装前记录全**：由桌面/任务栏/开始菜单快捷方式反推您实际在用的软件清单（而非系统装过什么），并记录鼠标、任务栏、默认浏览器、文件关联等个性化设置与各软件配置
- **重装后原样回来**：按记录自动重建——装回软件（一律最新版、建议装 D: 盘）、还原设置、恢复默认应用习惯，打开新系统"像没换过一样"
- **顺手优化**：批量卸载系统捆绑的软件（防病毒试用版、游戏、推广工具等）；把 TEMP、页面文件等大体积高读写缓存移到其它盘，延长 C 盘寿命
- **新机也能用**：附新机初始化清单与常用优化设置调研库（网络热点整理）

## 为什么要用？

重装系统最费的不是装系统，是"把电脑调回顺手的样子"——哪些软件要装、装在哪个盘、任务栏怎么摆、文件用什么打开，全靠脑子记。本技能把这套经验流程化：重装前记录、重装后重建，不以整盘镜像照搬，而是以使用者的使用需求为中心。仅针对 Windows 安装在 C: 的场景，并建议后装软件一律放非系统盘。

## 如何用？

1. 本技能是为 WorkBuddy 等智能体（Agent）准备的：安装到智能体的技能目录后，重装前说"备份一下我的电脑软件和设置"，重装后说"按记录重建我的电脑"，智能体按技能流程执行
2. 也可人工阅读本仓库 `SKILL.md`，按"采集端 / 恢复端"清单自行操作
3. 无重装计划时也可单独使用其中模块：新机初始化、捆绑软件卸载、缓存移盘

## 有问题怎么办？

- 某软件装不回去 → 技能按三级帮助模型处理：能自动的自动装，不能自动的给下载与安装指引，最后才是提示清单
- 卸载捆绑软件怕删错 → 技能默认保留驱动相关组件（声卡/显卡面板、触摸板、打印机、固件更新工具），不确定的项目先查名称再定
- 缓存移盘后想还原 → TEMP/页面文件路径改回 C: 原值即可，操作可逆
